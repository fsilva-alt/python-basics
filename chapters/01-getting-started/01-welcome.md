# Before you begin

![An illustration of a code editor, a terminal and an interactive Python prompt](assets/hero.svg){width=560}

Welcome! In this course you'll write your first real Python programs, one small step at a time. You don't need any programming experience: every new idea is explained the first time it appears, and you'll try each one yourself before moving on.

Python is a general-purpose programming language that is famous for being easy to read. People use it to automate boring tasks, analyze data, build websites, control hardware, teach programming, and much more. The skills you pick up here are the same ones professional developers use every day.

![The Python logo](https://upload.wikimedia.org/wikipedia/commons/c/c3/Python-logo-notext.svg "The Python logo, embedded from an external URL at build time"){width=120}

## Prerequisites

You only need a few basic computer skills:

- Installing an app on your computer.
- Creating a folder and saving a plain-text file.
- Opening a terminal (also called a command prompt or shell) and typing a command. If you've never done this, don't worry: the next chapter shows you how.

## What you'll learn

- How to install Python and check that it works
- How to try out code in the interactive shell
- How to write a program in a file and run it
- How to store information in **variables** and work with numbers and text
- How to make decisions with `if`, `elif` and `else`
- How to repeat work with **lists** and **loops**
- How to organize your code into reusable **functions**

## What you'll build

By the end of the course you'll have built a complete **Guess the number** game that runs in your terminal. The computer picks a secret number, and you try to find it with as few guesses as possible:

```text
Welcome to Guess the number!
I'm thinking of a number between 1 and 100.
Your guess: 50
Too high! Try again.
Your guess: twenty
Please type a whole number, like 42.
Your guess: 25
Too low! Try again.
Your guess: 37
You got it in 3 attempts!
Play again? (y/n): n
Thanks for playing!
```

It's a small program, but it uses every concept in the course: variables, input, decisions, loops and functions.

## What you'll need

- A computer running **Windows**, **macOS** or **Linux**.
- **Python 3.10 or newer.** You'll install or check it in the next chapter.
- **A text editor for code.** Any editor that saves plain text works. IDLE, a simple editor that comes with the official Python installers for Windows and macOS, is a fine choice if you don't have a favorite yet.
- **About 90 minutes.** Each chapter shows an estimated time, and you can stop and come back whenever you like.

:::tip Get the most out of this course
Type the examples yourself instead of copying and pasting them. It feels slower, but your fingers and brain learn much faster that way, and the typos you make (and fix!) are part of learning.
:::

:::note
Word processors such as the ones used for letters and reports add hidden formatting to files, so they can't be used to write code. Use a code editor or a plain-text editor instead.
:::
